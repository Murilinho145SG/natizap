# Emoji graphics

The SVG files in this folder are from Twemoji 15.1.0
(https://github.com/jdecked/twemoji), Copyright 2019 Twitter, Inc and
other contributors, licensed under CC-BY 4.0:
https://creativecommons.org/licenses/by/4.0/

File names are the emoji's code points in lowercase hex joined by `-`,
without U+FE0F unless the sequence contains a zero-width joiner.
